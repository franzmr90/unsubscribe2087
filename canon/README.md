# Canon — *Project Phonix*

The novel this game is the aftermath of. **Reference only. Nothing here is part of the build**
(`build.sh` only reads `src/`), and nothing here ships inside `dist/`.

## What's here

| Path | Contents |
|---|---|
| `manuscript/` | The book. 84 files, one per chapter/section, ~80,000 words. |
| `notes/story-bible.md` | Every fact the draft has established — characters, places, terminology. **Check here before inventing detail.** |
| `notes/outline.md` | Structure and plan. |
| `notes/ending.md` | How it ends. |
| `notes/analysis.md` | Developmental read of the draft. |
| `notes/overview-for-readers.md` | Plain-language summary of the whole story. |
| `notes/the-money-thread.md` | The economic/Bitcoin throughline — directly relevant to the game's credits, shitcoiners, and Bull Run content. |
| `notes/bitcoin-and-the-sandbox.md` | Worldbuilding on the money system. |
| `notes/predecessor.md`, `notes/the-providence-problem.md`, `notes/structure-v2.md` | Supporting worldbuilding and structure notes. |
| `front/`, `appendix/` | Preface, Bletchley prologue, "what's true" appendix. |
| `SOURCE-README.md` | The novel folder's own README. |

## Caveat

`SOURCE-README.md` is **stale** — it reports 12,182 words across 23 chapters. The actual
manuscript here is ~80,000 words across 84 files. Trust the files, not that README's counts.

## How to use this

The game is set in 2087, generations after the novel's events. It should feel like the
*consequence* of this book, not a retelling of it — a new player who has never read the novel
must still understand everything the game puts in front of them. Canon is the source of
meaning behind the game's terminology, factions, and economics; it is not a plot to recite.
