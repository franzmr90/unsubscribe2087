# Unsubscribe 2087

A Diablo 2-style action RPG. On a phone, a stick and buttons. On a desk, left click walks and strikes, right click casts, and the slots beside the orbs pick those skills. It's 2087, a loaf costs a million credits, and you took the visor off.

- Play: open `dist/Unsubscribe-2087-standalone.html` in a browser.
- Build: `./build.sh` (needs Node for the syntax check).
- How the code is laid out: see `CLAUDE.md`.
