# Acqui-hire names the rank that converts a champion

The card said champions resist until level 5. The row that holds the skill already needs character level 9, so the first time you can cast it the card has already given up. The cast still skips a champion until the skill’s effect rank is 5, the same rank the card shows, including gear and mastery.

A champion at character level 20 and rank 1 stays a machine. At rank 5 it comes over.
