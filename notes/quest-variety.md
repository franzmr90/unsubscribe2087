# Acts I–III quest variety

The story quests were one shape: walk into the district, break the named machine, return. Side errands already had other shapes (escort, a timed hold, a fetch across two districts). This pass does not add a quest engine. It hangs four story beats on the state the campaign already uses: unspoken, active, return, done.

Boss scenes are untouched. Exit Interview, The Voice, and Still Water still end the act when the executive falls. Acts IV and V are untouched.

## The Last Librarian (q3)

The cage was already a second beat. The corner still said “Destroy Defrag” after Defrag had fallen.

| | Corner |
|---|---|
| Before | Destroy Defrag. Follow the arrow. |
| After | Open Marrow’s cage in the Humming Fields. |

Killing Defrag still does not finish the quest. Opening the cage still does. An old save that already dropped Defrag picks the cage line up the next time the Fields are entered.

## The Audit (q4)

| | Before | After |
|---|---|---|
| How it starts | Walking onto Tribunal Row | Speaking to Sister Null, once the librarian is home |
| Corner, before that | Go to Tribunal Row and destroy Auditor Prime | Speak to Sister Null in town |
| If you walk in first | The quest starts itself | It does not. The corner still names her |
| If you break Auditor anyway | Return to Sister Null | Same. The turn-in is unchanged, so the books can still be closed out of order |
| Reward | 5 attribute points | 5 attribute points |

## What the Lake Remembers (q8)

Return to Sender, the errand after this quest, is still the one that carries three letters back to town. This beat is one page already above the water.

| | Before | After |
|---|---|---|
| The work | Destroy Lethe | Read the letter, and destroy Lethe. Either first |
| If Lethe falls first | Return to Marrow | The letter is still there. The quest waits |
| If you read first | — | The arrow turns to Lethe |
| Reward | 1 skill point | 1 skill point |

## Strike It From the Record (q12)

| | Before | After |
|---|---|---|
| The work | Destroy the Recording Secretary | Destroy it, then strike the minutes it already filed |
| When it falls | Return to Marrow | A minute-book is on the floor. The quest waits until you strike it |
| Turn-in | “I kept the ones from after.” | “You struck the page. It cannot file a meeting that has not happened.” |
| Reward | 1 skill point | 1 skill point |

A kill that already sent you back to Marrow, on an older save, stays sent. The book only appears for a secretary that falls after this change.

## Point of Order (q13)

| | Before | After |
|---|---|---|
| The work | Destroy the Chair | Break four directors, then the Chair |
| If the Chair falls first | Return to Nonce | The motion stays open until four directors have fallen. They do not have to be first |
| Reward | 60 sats | 60 sats |

The Chair does not count as one of the four. Directors drift back with the rest of the district, so the count cannot stall.
